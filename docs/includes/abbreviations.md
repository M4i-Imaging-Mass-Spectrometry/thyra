*[SpatialData]: An open format and Python library for spatial biology data, from the scverse community
*[Zarr]: The storage format under SpatialData: a folder of small files that can be read a piece at a time
*[AnnData]: The Python table format that holds the spectra: one row per pixel, one column per m/z bin
*[scverse]: A community of open-source Python tools for single-cell and spatial biology
*[CLI]: Command-line interface: the thyra command you type in a terminal
*[SDK]: Software development kit: here, the instrument maker's library that reads its raw files
*[TIMS]: Trapped ion mobility spectrometry: separates ions by size and shape as well as by m/z
*[PASEF]: Parallel accumulation-serial fragmentation: a Bruker timsTOF mode for MS/MS
*[ToF-SIMS]: Time-of-flight secondary ion mass spectrometry
*[FT-ICR]: Fourier-transform ion cyclotron resonance: a very high-resolution mass analyser
